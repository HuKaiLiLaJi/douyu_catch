一、目标

写一个斗鱼直播弹幕采集命令行工具，可以输入房间号，连接斗鱼弹幕服务器，实时接收 chatmsg 弹幕，并保存到 txt 文件。


二、最初实现

最开始实现的是斗鱼常见的原始 TCP 弹幕协议：

默认服务器：
openbarrage.douyutv.com:8601

登录消息：
type@=loginreq/roomid@=房间号/

加入弹幕分组：
type@=joingroup/rid@=房间号/gid@=-9999/

心跳：
type@=keeplive/tick@=时间戳/

消息格式：
斗鱼消息体使用 key@=value/ 的格式。
外层二进制包头包含长度、重复长度、消息类型等字段。


三、遇到的问题

1. openbarrage.douyutv.com 在当前环境中解析失败。
   报错类似：
   getaddrinfo failed

2. danmu.douyutv.com 可以解析，但 8601/12601 端口连接失败或超时。

3. 切换 VPN 到普通模式后，网页访问斗鱼恢复正常，但旧弹幕域名仍不稳定。

4. 抓房间 93589 时，终端遇到 emoji 等特殊字符，PowerShell 默认 GBK 编码无法打印，报：
   UnicodeEncodeError: 'gbk' codec can't encode character

五、当前推荐用法

在项目根目录运行：

cd "D:\Project J data\test_project"

抓取 30 条房间 93589 的弹幕：

python -m src.douyu_danmu 93589 --limit 30 --output douyu_93589_test.txt --host danmuproxy.douyu.com --port 8601

抓取 20 条房间 1126960 的弹幕：

python -m src.douyu_danmu 1126960 --limit 20 --output douyu_1126960_test.txt --host danmuproxy.douyu.com --port 8601

终端也输出 JSON：

python -m src.douyu_danmu 93589 --limit 30 --json --output douyu_93589_test.jsonl --host danmuproxy.douyu.com --port 8601

查看帮助：

python -m src.douyu_danmu --help


六、程序能力

当前程序支持：

1. 输入斗鱼房间号。
2. 实时连接弹幕服务器。
3. 自动发送 loginreq、joingroup 和 keeplive。
4. 解析 chatmsg 弹幕。
5. 输出字段：
   room_id
   nickname
   text
   user_id
   level
   raw_type
   received_at
6. 保存为 UTF-8 文件。
7. 限制采集条数。
8. 避免终端编码不支持 emoji 时直接崩溃。


七、测试

运行单元测试：

python -m unittest discover -s tests

当前测试覆盖：

1. 斗鱼 key@=value/ 格式的转义和反转义。
2. 斗鱼二进制包的打包和读取。


八、注意事项

1. 建议 VPN 使用普通模式或规则模式，不要全局代理斗鱼弹幕 TCP 连接。

2. 如果默认 openbarrage.douyutv.com 不通，推荐使用：
   --host danmuproxy.douyu.com --port 8601

3. 如果不加 --limit，程序会持续采集，按 Ctrl+C 停止。

4. 直播平台接口可能变化。如果以后连接失败，优先检查：
   - 房间号是否正确
   - 直播间是否开播
   - VPN 是否影响国内 TCP 长连接
   - danmuproxy.douyu.com:8601 是否还能连通
